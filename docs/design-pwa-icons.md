# Задание дизайнеру: иконки приложения (PWA) и перевыгрузка UI-иконок

Приложение стало устанавливаемым (PWA): офлайн-оболочка готова, но в
манифесте сейчас временно стоит SVG-марка `public/icons/buckitup_circle.svg`.
Для корректной установки на Android/iOS нужны растровые иконки из фирменного
знака BuckitUp.

## 1. Иконки установки (обязательные)

Все — PNG, точный квадрат, из векторного исходника знака (не апскейл).

| Файл | Размер | Назначение | Требования |
|---|---|---|---|
| `pwa-192.png` | 192×192 | Android/Chrome, минимум для установки | знак на фирменном фоне; прозрачность допустима |
| `pwa-512.png` | 512×512 | Android/Chrome, сплэш | то же |
| `pwa-512-maskable.png` | 512×512 | Android adaptive icon (`purpose: maskable`) | **фон залит до самых краёв, без прозрачности**; весь смысловой рисунок — внутри центрального круга Ø 80 % стороны (~409 px): системы обрезают иконку в круг/сквиркл |
| `apple-touch-icon.png` | 180×180 | iOS «на экран Домой» | **без прозрачности** (iOS зальёт прозрачное чёрным), углы не скруглять — iOS скругляет сам |

## 2. Опционально (желательно)

| Файл | Размер | Назначение |
|---|---|---|
| `pwa-monochrome.png` | 512×512 | Android 13+ «темированные» иконки (`purpose: monochrome`): белый знак на прозрачном фоне, один цвет |
| `favicon.svg` | — | современный favicon вместо/вдобавок к `favicon.ico` |

## 3. Цвета манифеста — подтвердить

Сейчас в манифесте `theme_color`/`background_color` = `#17161a` (тёмный из
борда). Если сплэш и строка статуса должны быть в акценте `#8e2b77` или в
`#241824` — сказать, поменяем.

## 4. Перевыгрузка UI-иконок (известная проблема из handoff-борда)

`public/icons/*.svg` выгружены с пустым `<defs>` — как CSS-маски они
рисуются сплошным квадратом. Нужна перевыгрузка всего набора (24-сетка,
stroke 2, #241824) с инлайновыми путями, без ссылок на `defs`/`use`.

## Куда сдавать

PNG-иконки — в `public/img/pwa/`, перевыгруженные UI-иконки — поверх
`public/icons/`. Подключение к манифесту (vite.config.js) сделаем сами по
факту получения файлов.
