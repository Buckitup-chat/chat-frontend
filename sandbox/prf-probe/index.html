Passkey PRF probe
Does this device's passkey support the PRF extension?
  1. Tap 1. Create passkey and confirm with your fingerprint, face or PIN.
  2. Tap 2. Get with PRF (this passkey) twice.
  3. Tap 3. Get with PRF (any passkey) once.
  4. Optional, on a computer: 4. Cross-device, then scan the QR code with a phone that already made a passkey on this page.
  5. Tap Copy report and paste it into the support table.

Nothing leaves this device: there is no server. The passkey is a throwaway test one named "prf-probe-…" (delete it afterwards in your password manager if you like). The page shows only short fingerprints of the PRF outputs, never the outputs themselves, and keeps only the passkey's id in this browser.
